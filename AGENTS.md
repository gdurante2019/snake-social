For backend development, use `uv` for dependency management.

A few useful commands:

# Sync dependencies from lockfile
uv sync

# Add a new package
uv add <PACKAGE-NAME>

# Run Python files
uv run python <PYTHON-FILE>

Regularly commit code to git
